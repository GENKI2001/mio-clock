# フェーズ 01: 状態・会話・手帳・保存

## 🎯 目的 (Objective)
全編の進行を安全に保存し、導入・ミオとの会話・手帳・文書を表示できる土台を作る。

## 🛠️ 技術的な方針 (Technical Approach)
- GameProgressを仕様書§3へ拡張し、旧試作データを読み込めるようにする。
- 会話と文書をデータとして分離し、モーダル・自動メモを共通化する。

## 📝 ステップバイステップ
1. [x] 全状態、所持品、文書、メモ、既読、結末回収を保存・復元する。
2. [x] 導入、初回の出会い、見送り、会話メニューを実装する。
3. [x] 手帳をメモ・文書の2タブにする。

## ✅ 受け入れ条件
- [x] 時代切替、会話、取得文書の進行が再起動後も戻る。
- [x] 時計を持っている間の歯車は時代を越えない。

## 🧪 テスト・検証方法
- flutter analyze と flutter test。
- iPhoneシミュレータで導入から手帳まで操作し、再起動して確認する。
